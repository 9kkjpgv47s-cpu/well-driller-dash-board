## Notes

- `zoomStep → refresh calls` was 0 in A/B and is 1–2 in C: the zoom-in click actually produces a refresh now (coalesced); A/B's 0 was the Leaflet zoom-control click being hit-tested oddly in headless — settle is measured but no zoom occurred. Not a regression.
- `pan→refresh calls` ipad/phone shows 2 in C: the 400ms mid-burst backstop can overlap the 120ms trailing fire on a slow gesture — bounded at ≤2, end state identical (markers gate passes).
- A-profile wheel metrics are 0 on ipad/phone because the pre-restyle baseline did not wire trackpad wheel-pan on those contexts — so C vs B is the meaningful comparison.
- Load time is dominated by DNR chunk fetch+parse (data, unchanged); the spatial index adds ~50ms once per chunk merge.
